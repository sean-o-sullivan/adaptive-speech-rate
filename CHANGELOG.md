# Changelog

## 0.1.0 — 2026-08-20

- Direct, local YouTube audio capture through `captureStream()`.
- Source-media-time speech activity, syllable-nucleus, and articulation-rate estimation.
- Confidence-gated adaptive playback with robust filtering, deadband, bounds, and asymmetric slew limits.
- Compact in-page control with expandable diagnostics and one-click music bypass.
- Persisted target, analysis-window, and playback-bound controls in the extension popup.
- Local-only processing with YouTube-only host access and `storage` as the sole API permission.

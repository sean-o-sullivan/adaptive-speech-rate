# Adaptive Speech Rate Project

Read, in order:

1. `docs/EXECUTION_BRIEF.md` — controlling product brief.
2. `docs/ARCHITECTURE.md` — current component and timing boundaries.
3. `docs/CONTROL_MODEL.md` — equations, state machine, and defaults.
4. Latest entries in `docs/EXPERIMENTS.md` — observed results and current blocker.

All project work stays in this directory. Do not connect the controller to real playback until direct audio capture and detector speed-invariance have been demonstrated in Dia. Preserve source-media timing, pause-hold behaviour, confidence gating, and local-only processing.
